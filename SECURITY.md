# Security Policy

## Scope

ViralMint is research software. Do not submit private keys, seed phrases, exchange credentials, or other secrets in issues or pull requests.

## Reporting

Report suspected vulnerabilities privately to the repository owner through GitHub's security advisory/reporting features when available. Include affected versions, reproduction steps, and impact. Avoid publishing exploit details before a fix can be coordinated.

## Safety boundaries

The project does not execute trades or connect to wallets. Market scores are heuristic and must not be interpreted as a guarantee of token safety or future performance.
